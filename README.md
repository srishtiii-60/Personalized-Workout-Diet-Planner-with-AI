# Personalized Workout & Diet Planner with AI

A modern fitness and nutrition planning web application inspired by the Fitly concept. The project provides a personalized dashboard for workouts, meal planning, progress tracking, preferences, and an AI-style assistant.

## Featuers

- Personalized fitness dashboard
- Workout plan and completion tracking
- Meal plan with calorie and macro overview
- Progress and consistency tracking
- User preference section
- Smart meal-swap interaction
- Built-in chatbot-style assistant
- Responsive layout for desktop and mmobile
- Clean green wellness-focused UI

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Responsive design
- Client-side recommendation/chat demo

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a browser.

For local development, VS Code + Live Server can be used.

## Note

This repository is a front-end demonstration. The chatbot and personalization logic are implemented locally for demonstration purposes. A production version can connect the interface to a secure backend, database, authentication provider and an AI API.
